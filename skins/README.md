# 录音纪要皮肤包（v1.3.0）

> 皮肤与内容完全无关：装饰文案走 `content:attr(data-*)`，由渲染器把标题写进 DOM 属性；六张 `previews/*.png` 均为 `examples/split-示例.json` 的虚构示例。发布前核对见 `../发布自查清单.md`。

六种展示视觉效果，供用户在**意图问卷完成后、生成前**选择。注册表见 `skins.json`，每种皮肤一张预览图在 `previews/`。

## 皮肤清单

| id | 名称 | 文件 | 一句话 |
|---|---|---|---|
| default | 模板原生 | （无） | 模板原生样式，不加皮肤层 |
| mist | 灰蓝粉彩 | skin-mist.css | 灰蓝画布＋四节粉彩分色＋双列白芯卡片，单页长文、信息密度高 |
| obsidian | 黑曜潮青 | skin-obsidian.css | 黑曜底 #07080A＋骨白正文＋四节深夜分色（暗红/暗绿/暗蓝/暗金）＋薄荷 #8BF3E6 强调，结构与灰蓝粉彩一致 |
| plain | 素白极简 | skin-plain.css | 纯白无卡无阴影＋发丝线分栏＋38:62 左窄右宽（分隔条可拖动）＋紫粉渐变标题，单列大纲整页一滚 |
| dark | 深蓝学术 | skin-dark.css | 深藏青＋蓝图网格＋宋体标题，声线带律动动效 |
| neutral | 中性灰阶 | skin-neutral.css | #F7F7F7 中性画布＋白卡 1px 描边＋唯一强调 #335CFF，Badge/Filter/Table 组件语义、克制阴影 |

默认皮肤：mist（用户不选时用它）。

### 预览图说明

`previews/` 下六张 PNG（default / mist / obsidian / plain / dark / neutral）全部由 `examples/split-示例.json` 的虚构示例渲染，图中的标题、角色、日期与正文均为演示用途，不含任何真实材料、真实机构或第三方品牌。预览只展示视觉风格，与实际录音内容无关。

## 选择环节（接进问卷流程）

1. 意图问卷（转写/纪要的意图确认题）全部答完之后、开始生成之前，插入一步「选择展示视觉效果」。
2. 展示方式：六张预览图（previews/*.png）+ 皮肤名 + 一句话描述，让用户点选其一。
3. 记下所选 id，按下面方式注入生成；用户跳过/不选 → default_skin = mist。

## 注入方式（必须照此）

- 把所选皮肤 CSS 全文放进一个**独立的** `<style data-skin="<id>">` 元素，置于主 `<style>` 之后、`</head>` 之前。
- **禁止**把皮肤 CSS 拼接到主 style 的末尾：主 style 一旦存在未闭合注释，追加到末尾的样式会被整段静默吞掉；独立元素注入是可靠方式。
- default 皮肤不注入任何东西。
- 皮肤与内容完全无关：只含 `@media screen` 视觉规则，不动 DOM、文本、脚本、音频引用；同一份纪要换皮肤重出即可。打印时皮肤自动不生效，走模板原始打印样式。
- dark 皮肤含动画（节奏条律动＋光带扫过）；系统开启「减少动态效果」（prefers-reduced-motion）时自动停，不用额外处理。
- neutral 是覆盖式实现：先关掉模板的光晕 / 渐变 / 颗粒 / 品牌光带，再按 `../设计参考-中性界面规范.md` 的组件对位表重铸视觉。它不新增交互，所有需要 JS 的组件（Command Menu、Drawer 等）明确不迁移；预览图为虚构示例，与内容无关。

## 版式与播放条（v1.3.0：双栏独立滚动）

**桌面并排（视口 ≥ 921px）统一「双面板内滚」，不再按皮肤分两套版式**：`#colL`（纪要）与 `#colR`（转写全文）各自是滚动容器，滚轮 / 拖动滚动条只作用于指针所在的那一栏；`overscroll-behavior:contain` 保证滚到栏底也不会带动整页或另一栏。点左栏目录只滚左栏，点右栏时间码只滚右栏。`html,body` 锁死不滚。窄屏（≤920px）回到单列整页滚动，打印走独立规则。

规则落在 `templates/split/page.css` 末尾的「双栏独立滚动」层，用 `!important` 盖过 mist / plain / dark 皮肤里遗留的整页滚动覆盖；皮肤文件只保留视觉样式，`position:sticky/fixed` 的播放条在桌面被强制回 `static`，靠面板 flex 列自然常驻右栏底部。

| 区域 | 滚动容器 | 播放条 |
|---|---|---|
| 桌面 ≥921px（所有皮肤） | `#colL` / `#colR` 各自内滚 | 常驻右栏底部（不滚动） |
| 窄屏 ≤920px（单列） | `body` 整页滚 | `position:sticky; bottom:0` 钉在视口底部 |

播放条**始终留在「转写全文」右栏的宽度内**，不做全幅横跨；控件沿用模板原始样式（圆形播放键 + 3px 进度条），皮肤只改配色，不改形状与位置。另有音量滑杆、静音、选本地音频三个控件（视口 <1180px 时隐藏音量滑杆）。

- **历史原因（v1.2.x）**：曾按皮肤分「双面板内滚 / 整页滚动」两套。整页滚动时 `.player` 是 `#pR` 最后一个子元素，会落在上万像素处，只能靠 sticky 钉住；也正因如此两栏会被整页滚动一起带走。v1.3.0 起统一内滚，sticky 不再是桌面必需。
- **`filter` / `backdrop-filter` 会造包含块**：父级有这两者时 `position:fixed` 会相对父级而非视口，钉不住。plain 因此显式设 `#pR{backdrop-filter:none}`。
- **JS 自适应**：`templates/split/page.js` 的 `detectScrollMode()` 只读 `#colL` 的 `overflow-y` 判断是否面板内滚（不再用 `scrollHeight/clientHeight`——短内容会误判成整页滚动，去滚一个已锁死的 body）；`onScroll()`、目录锚点点击、回顶按钮保留两套分支。新增皮肤不用动 JS。
- **节奏条刻度**：`buildAxis(dur)` 按总长自适应（>30 分为 5 分钟刻度、>10 分为 2 分、>4 分为 1 分、>90 秒为 30 秒、其余 15 秒，短音频显示秒档）。旧版写死 `[0,5,10,15]`，31 分钟的音频右半段是空白。
- 页面顶部尚未越过探测线时，副导航默认高亮第一章；脚本初始化时主动跑一次 `onScroll()`，内容不足一屏也能高亮。

## 分栏宽度（可拖动）

两栏并排时（视口 ≥ 921px），中间有一条可拖动的分隔条：

- **拖动** 调整左右栏宽度，范围 26%–78%；移动不足 3px 视为单击、不改变宽度；**双击** 恢复该皮肤的默认比例；聚焦后可用 **←/→** 每次 2%。
- 各皮肤默认：`default`/`mist`/`dark` 56:44，`neutral` 55.5:44.5，`plain` 38:62（正文占大头）。
- 拖完记进 `localStorage`（键 `zcdg.split.<页面路径>`），刷新保持；换文件互不影响。
- 未拖动时不写任何变量，各皮肤按自己的 `grid-template-columns` 排版——**加新皮肤不用管这条**。
- 窄屏（≤920px）自动隐藏分隔条并回到单列。

## 命名说明

皮肤名称与描述全部按**各自实际视觉特征**命名（灰蓝粉彩 / 黑曜潮青 / 素白极简 / 深蓝学术 / 中性灰阶），不使用任何第三方产品的品牌名、商标或「同款」式表述。

## 版式变更记录

### v1.4.1 — 倍速改为下拉选择（2026-11-11）

原先是**循环切换**：每次点一下在 `1 → 1.25 → 1.5 → 0.75 → 2` 之间跳一格，想从 1.0 到 0.75 得点四次，且档位顺序反直觉。

改为**弹出菜单**：点倍速框展开 6 档（`0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0`），当前档打勾高亮，点选中项才生效；`Esc`、点空白处、滚动右栏、改窗口大小都会收起。选择记进 `localStorage`（键 `zcdg.rate.v1`），刷新后沿用，并在 `loadedmetadata` 时重新套一次（换音频后 `playbackRate` 会复位）。

**踩坑（重要）**：菜单最初用 `position:absolute` 放在播放条里，被 `.player` 的 `overflow:hidden` 裁掉；改成 `position:fixed` 后仍然错位到屏幕外 —— 因为 `#pR` 上有 `backdrop-filter`，它会为 `position:fixed` 造包含块，fixed 变成相对面板定位。最终做法是**把菜单节点 append 到 `document.body`** 再用按钮的 `getBoundingClientRect()` 实时算坐标，并做视口夹取（上方不够就翻到下方）。这个坑和 v1.2.3 里 plain 皮肤 `#pR{backdrop-filter}` 导致 `position:fixed` 钉不住是同一个原因。

### v1.4.0 — 新增「黑曜潮青」深色皮肤、素白极简播放条贴底（2026-11-11）

**新皮肤 `obsidian`（黑曜潮青）**
- 结构与 `mist` 完全一致（粉彩壳/白芯卡片双列、✦ 分节、浅蓝决策面板、转写层级），
  只替换配色层：把整套浅色值映射成「黑曜底 + 骨白正文 + 四节深夜分色 + 薄荷强调」。
- 配色取值：底色 `#07080A`、主文字 `#F3F5F8`、次级 `#9AA2AD`、弱化 `#5B636E`、
  强调薄荷 `#8BF3E6`、潮蓝 `#46B7FF`、发丝线 `rgba(255,255,255,.10)`。
  强调色用**低透明度叠加**（`.1/.12/.18`），不铺满色块。
- 深色底上有四处模板写死的浅色容器必须一起换面，否则会露出白块：
  `.pill`、`.card`、`.rhythm-bars`、`.pl-speed`（都是 `background:#fff`）。
- 正文色 `--slate` 在深色必须改成骨白系（`#D7DCE4`）——它同时被 `.seg-x` 与
  `.brief li` 使用，不改则转写正文是深蓝灰，在黑底上读不出。
- `.pl-play` 是薄荷底，模板默认图标 `color:#fff`，在亮薄荷上几乎看不见，改为 `#07080A`。

**素白极简播放条贴底**
- `skins/skin-plain.css` 的 `.app` 底部内边距 `64px → 0`，播放条下方不再留 18px 空隙。
  该 padding 原本是为「整页一滚」留的呼吸位，统一改为双面板内滚后已无必要。

### v1.3.3 — 板块标题与上文拉开距离（2026-11-11）

灰蓝粉彩 / 深蓝学术把 s1–s3 合成一整块浅灰面（`.doc` + `#s1,#s2,#s3` 统一底色），
配套写了 `#s1{margin-top:0}` / `#s2,#s3{margin-top:0}` —— 副作用是**板块标题直接贴住
上方结论框**，视觉上像标题被挤上去。模板原有的 `.sec{margin-top:34px}` 被这段覆盖掉。

改为用**内边距**而不是外边距来造间距（合并块内用 margin 会破开连成一体的背景）：

```css
#s1{margin-top:0;padding-top:30px}
#s2,#s3{margin-top:0;padding-top:32px}
```

板块标题上方间距统一为 30–34px（s5 为 26px，它前面是 duel 对照面板）。

### v1.3.2 — 播放条改为内嵌卡片、页面去「两个浮动文本框」（2026-11-11）

**播放条**（`templates/split/page.css`）
- 从「只有上边框、贴底、与正文同色」改为**完整四边框卡片**：`border:1px` +
  `border-radius:14px` + `margin:8px 18px 18px`，底色走 `--player-bg`（默认 `#F7F8FA`，
  比正文面板浅/亮一档，靠颜色就把播放器和正文分开，不靠分割线压字）。
- 结构改为「说明行 → 进度线 → 控件行」：说明行由模板 `.player::before{content:attr(data-caption)}`
  统一提供（原先只有 mist/dark 有，plain/neutral 没有），样式是卡内**普通说明文字**，
  不再是第二个带边框的白胶囊；进度线提到卡片最上沿（`order:-2`）。
- 转写区底部留白 24 → 40px，最后一行文字不再顶到播放条边缘。

**页面整体**（`skins/skin-mist.css` 等）
- 去掉 `.panel` / `#pR` 的圆角、外阴影与 `filter:drop-shadow`，页面从
  「灰底 + 两个悬浮白卡」变成**一张整页白纸 + 一条竖向分栏线**；
- mist 的 `body` 底色由渐变灰改纯白；`#pR .p-hd` 的圆角/阴影/外边距清零，改为下边线。

**注意（踩坑）**：三套皮肤原先各自写了 `.player{height:var(--pl)}` 锁死高度，
会盖掉模板的卡片几何——表现为「有边框但圆角 0、说明行被压成 2px」。
现统一为：**播放条几何只由模板管，皮肤只改配色**。

### v1.3.1 — 单一来源的 7 级字阶（2026-11-10）

## 字号与层级（v1.3.1：单一来源的 7 级字阶）

曾有 30 多个互不相同的字号：正文层挤着 13.2 / 13.4 / 13.5 / 13.6 / 13.8px 五档近似值，
而板块标题（h3）与卡片标题（h4）同为 14.5px——层级在视觉上是平的，正文也偏小。

现在全部收敛到 `templates/split/page.css` `:root` 里的一组 token：

| token | 值 | 用途 |
| --- | --- | --- |
| `--fs-xxl` | 26px | 页面主标题 h1 |
| `--fs-xl` | 20px | 板块标题 h3 |
| `--fs-lg` | 17px | 卡片/条目标题 h4、页签 |
| `--fs-md` | 15px | **正文、转写全文（阅读主体）** |
| `--fs-sm` | 13.5px | 次要正文、说明、摘要 |
| `--fs-xs` | 12px | 元信息、时间码、标签、控件 |
| `--fs-xxs` | 10.5px | 序号、时间轴刻度、极小标记 |

行高同样收敛为 `--lh-md:1.75` / `--lh-sm:1.6`。**要改字号只改这 7 个值**，
全部模板与四套皮肤都引用它们，不必逐条改选择器；新增皮肤同理。

配套调整：

- 正文基准 14px/1.8 → **15px/1.75**；
- 正文类元素统一 `max-width:40em`，宽屏不再出现 59 字长行（复核为 31–40 字/行）；
- 页脚声明 11.5 → 13.5px，时间戳 10.5 → 12px；
- 时间引用 `.cite` 内边距 `0 4px` → `1px 5px`，点击高度 18 → 20–22px；
- 中性灰阶：说话人列 78 → 62px、栏比 1.28:1 → 1.12:1，正文每行 22 → 31–36 字；
- 打印字号同步放大（9 → 9.5pt，h1 15 → 17pt）。

复核四套皮肤计算字号一致且严格递减 `26 / 20 / 17 / 15 / 13.5 / 12 / 10.5`，
正文类最小 12px（仅时间戳等辅助信息）。

## 验证结论

六套皮肤均为纯 CSS 覆盖层，不改 DOM / 文本 / 脚本 / 音频；模板原有的搜索、筛选、引用跳转、清单、节奏条等交互保持不变。`neutral` 的视觉基线为：画布 #F7F7F7、白卡描边 #EBEBEB、标题 h1 无装饰渐变、装饰层 display:none。
